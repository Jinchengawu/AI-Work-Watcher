# AI-Work-Watcher

Use AI-Work-Watcher only for explicitly registered projects.

During Prepare, inspect the original Prompt and key project context, then present a Task Brief containing the goal, context, constraints, acceptance criteria, unknowns, recommended workflow, and refined Prompt. Do not record the task or modify project assets before approval.

During Finish, record only a compact outcome, verification evidence, rework reasons, optional numeric efficiency metrics, and the five evidence-backed dimensions documented by the project protocol. Never store transcripts, full model responses, source code, diffs, patches, terminal output, or secrets. A failed outcome has unknown result-adjusted efficiency.

Promote only successful Prompts or workflows, show the exact asset first, and require approval. Generate trends only after three completed tasks and current user confirmation. Every repeating pattern needs evidence from two independent tasks. Project modifications require a proposal with a validation metric and rollback condition.
